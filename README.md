# Керування кольорами — навчальний React-проєкт

Невеликий навчальний застосунок на React і TypeScript. Три кнопки окремо змінюють фон сторінки, колір тексту та колір усіх кнопок. Проєкт демонструє компоненти, типізацію `props`, обробку подій і керування станом через `useState`.

## Мета проєкту

- створити повторно використовуваний компонент кнопки;
- передавати компоненту дані та обробник події через `props`;
- типізувати `props` за допомогою TypeScript;
- зберігати й оновлювати стан React;
- запускати, перевіряти та збирати застосунок за допомогою Vite.

## Можливості

- **Змінити фон** — циклічно перемикає колір фону сторінки;
- **Змінити текст** — циклічно перемикає колір тексту;
- **Змінити кнопки** — змінює колір усіх трьох кнопок;
- під поточними налаштуваннями відображаються актуальні HEX-коди кольорів.

Кожна кнопка змінює тільки відповідний стан. Після завершення палітри колір повертається до початкового.

## Технології

- React 19;
- TypeScript 7;
- Vite 8;
- CSS.

## Вимоги

Потрібні Node.js і npm. Використовуйте версію Node.js, сумісну з установленою версією Vite.

## Запуск локально

1. Перейдіть у кореневу папку проєкту.
2. Встановіть залежності:

	```bash
	npm install
	```

3. Запустіть сервер розробки:

	```bash
	npm run dev
	```

4. Відкрийте адресу, яку Vite виведе у терміналі (зазвичай `http://localhost:5173/`).

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити локальний сервер розробки з HMR |
| `npm run typecheck` | Перевірити типи TypeScript без створення збірки |
| `npm run lint` | Запустити ESLint |
| `npm run build` | Перевірити TypeScript і створити production-збірку в `dist/` |
| `npm run preview` | Локально переглянути вже зібрану версію |

TypeScript-код перевіряється командами `npm run typecheck` і `npm run build`. Поточна конфігурація ESLint застосовується до JavaScript/JSX-файлів.

## Структура проєкту

```text
my-react-app/
├── index.html
├── package.json
├── tsconfig.json
└── src/
	 ├── App.tsx
	 ├── App.css
	 ├── index.css
	 ├── main.tsx
	 └── components/
		  └── Button.tsx
```

- [src/App.tsx](src/App.tsx) — головний компонент, стани кольорів і використання кнопок;
- [src/components/Button.tsx](src/components/Button.tsx) — типізований компонент кнопки;
- [src/main.tsx](src/main.tsx) — точка входу React-застосунку;
- [src/App.css](src/App.css) і [src/index.css](src/index.css) — стилі компонентів і глобальні стилі.

## Компонент кнопки та props

`Button` приймає такі props:

| Prop | Тип | Призначення |
| --- | --- | --- |
| `text` | `string` | Текст на кнопці |
| `type` | `'button' \| 'submit' \| 'reset'` | HTML-тип кнопки |
| `onClick` | `MouseEventHandler<HTMLButtonElement>` | Обробник кліку |
| `style` | `CSSProperties` (необов’язковий) | Inline-стилі; у цьому проєкті задає колір кнопки |

Наприклад, батьківський компонент передає текст, тип і функцію-обробник. Після кліку `App` оновлює стан через `useState`, а React перемальовує інтерфейс із новими кольорами.

## Збірка для розгортання

Створіть production-збірку:

```bash
npm run build
```

Готові статичні файли буде створено в папці `dist/`. Для локального перегляду збірки виконайте `npm run preview`.
